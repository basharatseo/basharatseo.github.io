# Muhammad Basharat — Portfolio

SEO Manager portfolio site, built as a single static HTML page (no build tools needed).

## Files
- `index.html` — the whole site
- `assets/profile.png` — profile photo

## Kaise GitHub par daalna hai (GitHub Pages)

1. GitHub par ek naya repository banao — naam kuch bhi rakh sakte ho, e.g. `portfolio` ya `basharatseo.github.io` (agar username-named repo banao ge to URL seedha `https://<username>.github.io` ban jayega).
2. `index.html` aur `assets` folder us repo me upload kar do (GitHub web UI se "Add file → Upload files" bhi kaam karega, ya git se push karo).
3. Repo ke **Settings → Pages** me jao.
4. "Source" me `main` branch aur `/ (root)` select karo, phir Save.
5. 1-2 minute me tumhari site live ho jayegi is URL par: `https://<username>.github.io/<repo-name>/`

## Update karne wali cheezein
- **Looker Studio link**: `index.html` me search karo `lookerstudio.google.com` — us link card ka `href="#"` apne asal report ke link se replace kar do.
- **Photo**: `assets/profile.png` ko replace kar do agar koi behtar/professional headshot use karna ho.
- **Content**: Experience, skills, ya about wala text seedha `index.html` ke andar edit ho sakta hai — sab plain HTML hai.

Koi build step, framework, ya npm install nahi chahiye — bas file upload karo aur Pages on kar do.
